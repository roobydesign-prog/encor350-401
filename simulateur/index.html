1. Core Concepts & Architecture

Review key architecture, virtualization, and infrastructure protocols required for the exam.

SD-Access & SD-WAN

  • Control Plane (SD-Access): Uses LISP (Locator/ID Separation Protocol).
  • Data Plane (SD-Access): Uses VXLAN encapsulation.
  • SD-WAN Planes: Management (vManage), Control (vSmart via OMP), Data (IPsec tunnels).
